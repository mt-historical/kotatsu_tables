# Kotatsu Table

This mod adds kotatsu tables, as well as an API for other mods to register
their own kotatsu tables in addition to the default wool ones.

## API

See [API.md](/API.md) for a complete listing of all api's this mod provides.

## Dependencies

- Luanti/Minetest v5.10
- MTG provided mods `default` and `wool`
